# Visionary Prompt Studio

**Visionary Prompt Studio** is a professional AI image prompt generator designed to transform creative ideas into detailed, platform-optimized prompts. It provides a director-style workflow for controlling subject, scene, visual style, lighting, color, composition, camera settings, textures, negative prompts, and creative direction.

The tool supports **Midjourney, DALL·E 3, Stable Diffusion, Adobe Firefly, and Ideogram**, with platform-specific prompt formatting and guidance. It also includes a **Prompt Quality Score, prompt metrics, variation generation, variation history, one-click copying, reset controls, and a “Surprise Me” randomizer** for rapid experimentation.

### Key Features

* 🎨 Multi-platform AI image prompt generation
* 🎬 Director-style creative controls
* 💡 Lighting, mood, color & composition customization
* 📷 Camera, lens, aspect ratio & quality controls
* 🚫 Negative prompt support
* 📊 Real-time prompt quality scoring
* 🔄 Prompt variations & history
* 📋 One-click prompt copying
* 🎲 “Surprise Me” creative randomizer
* ⚡ Responsive, interactive single-page interface

Built to help creators, designers, marketers, and AI artists **craft better prompts faster and with greater creative control**.
